Method used

Represent the rating matrix as R ≈ P Qᵀ. A predicted rating is the dot product pᵤ · qᵢ. For each known rating, error is eᵤᵢ = rᵤᵢ − pᵤ · qᵢ.

With regularization λ, update the factors using the previous values: pᵤ ← pᵤ + α(eᵤᵢqᵢ − λpᵤ) and qᵢ ← qᵢ + α(eᵤᵢpᵤ − λqᵢ). The factors start near √(mean rating ÷ factor count), with small seeded random variation. For each epoch, observed ratings are shuffled and updated one at a time. The epoch loss is half the squared rating error plus half the regularization penalty.
