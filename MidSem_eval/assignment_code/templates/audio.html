Practical III - Features from twelve machine recordings

Objective: describe and compare recorded machine sounds, including changes within each clip. These are twelve separate, real five-second ESC-50 recordings from six sound types, with two independent sources per type. They are examples of sounds, not evidence of machine faults.

From recording to results: SciPy resamples each checked 44.1 kHz mono WAV to 16 kHz mono. We divide it into five one-second windows, calculate four features with NumPy, and use Flask to display the audio, recording summary, selected measurements and Matplotlib plots.

What is sampled? Each recording has five one-second windows. At 16,000 samples per second, a window contains 16,000 amplitude measurements and a whole clip contains 80,000. Twelve recordings give 60 timestamped feature rows.

Why these features? Maximum amplitude records the strongest absolute sample in a window; RMS summarizes average signal strength; zero-crossing rate describes sign-change activity; spectral centroid describes frequency balance. Together they summarize different properties that are difficult to compare from raw waveforms alone. Microphone distance, recording gain, noise and bandwidth also affect them, so a single value cannot diagnose a fault.
