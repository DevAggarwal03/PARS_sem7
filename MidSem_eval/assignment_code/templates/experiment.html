VII — Linear regression with gradient descent

Assignment aim: implement Linear regression in python (no inbuild function should be used) to find optimized parameters using Gradient descent for any application and Plot Gradient Descent curve.

What the program does

It predicts Iris petal width from petal length. It reserves 20% of flowers for testing, scales petal length using training data, and manually updates the line's intercept and slope to reduce mean squared error.

Prediction: width = intercept + slope × scaled petal length

Weight update: weights ← weights − 0.05 × MSE gradient

VIII — Binary and multiclass logistic regression

Assignment aim: implement Logistic regression for binary class and multiclass classification in python (no inbuild function should be used) to find optimized parameters using Gradient descent for any application and Plot Gradient Descent curve.

What the program does

Both models use Iris petal length and width. The binary model predicts setosa versus other species with sigmoid. The three-class model predicts setosa, versicolor, or virginica with softmax. Their losses, gradients, and weight updates are coded directly with NumPy.

Binary probability = sigmoid(weighted measurements); three-class probabilities = softmax(three scores)

Weight update: weights ← weights − 0.1 × cross-entropy gradient

IX — Regularization and decision boundaries

Assignment aim: Implement regularization for any application show plots of 1)decision boundary and 2)performance before and after applying regularization.

What the program does

It separates Iris versicolor from virginica using petal length and width plus three quadratic combinations. The same training and test split is used twice: once without regularization and once with an L2 weight penalty. Both models use the manually coded binary logistic trainer.

L2 training objective = cross-entropy + penalty × sum(non-intercept weights²) ÷ (2 × training count)

Regularization discourages large weights and can change the shape of the decision boundary.
