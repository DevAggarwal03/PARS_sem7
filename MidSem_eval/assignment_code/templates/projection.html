What the program does

It reduces two Iris measurements, petal length and petal width, to one coordinate. The direction is fitted using only training flowers. {{ method }} A held-out flower is assigned to the nearest class centre on the reduced line.

Reduced coordinate z = (flower − training centre) · direction

Point on line = training centre + z × direction
